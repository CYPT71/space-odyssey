# Antigravity Space Simulator

🚀 **Immersive 3D space portfolio** - A cosmic engineer's deep space observatory terminal.

## Quick Start

```bash
# Install dependencies
bundle install

# Run development server
bundle exec jekyll serve

# Visit http://localhost:4000
```

## Project Structure

- **`content/`** - Site content (Markdown pages)
- **`theme/`** - Visual assets & 3D simulation code
- **`_tech/`** - Technical docs, tests, config

See [`_tech/docs/PROJECT_STRUCTURE.md`](_tech/docs/PROJECT_STRUCTURE.md) for detailed structure.

## Features

- ✨ Immersive 3D space navigation
- 🌍 Procedurally generated planets
- 🎮 Flight simulator controls
- 📡 Interactive navigation HUD
- 🔊 Dynamic audio system
- 💫 Particle effects & atmospheres

## Tech Stack

- **Frontend**: Three.js, JavaScript ES6+
- **Build**: Jekyll, Ruby
- **Testing**: Jest
- **Quality**: ESLint, Pre-commit hooks
