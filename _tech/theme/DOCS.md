# 🌌 Antigravity - Technical Documentation
**Version:** 3.0.0 (Cosmic Engineer Edition)
**Author:** CYPT71

## 📚 Overview
Antigravity is a high-performance, procedural space simulation engine built with **Three.js**. It features a seamless infinite universe, realistic physics, procedural generation, and an immersive "flight simulator" experience designed for a portfolio showcase.

---

## 🏗️ Architecture
The project follows a **Modular Functional Architecture**. Instead of monolithic classes, we use specialized functional modules that are composed in the main orchestrator (`space-scene.js`).

### Core Modules (`theme/assets/js/systems/`)
| Module | Description | Key Features |
|--------|-------------|--------------|
| `space-scene.js` | **Orchestrator** | Initializes scene, loop, and connects all systems. |
| `ship-controls.js` | **Physics & Input** | Inertia-based flight, Warp 1-5, Reverse, Gravity. |
| `camera-controller.js` | **Camera System** | Rigid follow, Reverse Cam (180°), Speed Shake. |
| `procedural-planets.js` | **Generation** | Massive scale planets, 3D distribution, Atmospheres. |
| `asteroid-system.js` | **Instancing** | Infinite asteroid fields using `InstancedMesh` & Generators. |
| `atmosphere-system.js` | **Shaders** | Reactive GLSL atmospheres using `Proxy` & `WeakMap`. |
| `navigation-hud.js` | **UI/UX** | 3D Waypoints, Off-screen indicators, Distance tracking. |
| `scanner-system.js` | **VFX** | Sonar wave shader (Tab key), Object detection. |
| `audio.js` | **Sound Engine** | Procedural engine drone, Warp sounds, Ambient wind. |

## 🎮 Controls
The control scheme is designed for a "Sim-Lite" experience with weight and inertia.

| Key | Action | Description |
|-----|--------|-------------|
| **Z** | Forward / Warp+ | Increase forward speed (Impulse -> Warp 5). |
| **S** | Backward / Warp- | Decrease speed or enter Reverse (Warp -1 to -3). |
| **Q / D** | Yaw Left / Right | Turn ship left/right. |
| **A / E** | Strafe Left / Right | Lateral movement (Dodging). |
| **W / X** | Pitch Up / Down | Nose up/down. |
| **R / F** | Roll Left / Right | Barrel roll. |
| **Space** | Ascend | Vertical strafe up. |
| **Shift** | Descend | Vertical strafe down. |
| **Tab** | Scanner | Trigger sonar pulse to find objects. |
| **C** | Stop | Emergency brake (Speed 0). |

## 🔧 Key Systems Breakdown

### 1. Infinite Universe (Modulo System)
Instead of moving the ship to infinity (which causes floating point errors), we move the **Starfield** relative to the ship using modulo arithmetic.
- **File:** `particles.js`
- **Logic:** `star.position.x = (originalX - shipX) % cubeSize`
- **Result:** Seamless infinite space without loading screens.

### 2. Gravity (Space Engineers Model)
Gravity is not a simple inverse-square law (which is annoying for gameplay). We use a **Linear Falloff** model.
- **File:** `ship-controls.js`
- **Logic:** Gravity is 100% at surface, 0% at `4 * radius`.
- **Effect:** Gentle pull that allows easy orbiting but requires thrust to escape. Only active at low speeds (Impulse).

### 3. Procedural Generation (Generators)
We use ES6 Generators (`function*`) for lazy evaluation of asteroid fields.
- **File:** `asteroid-system.js`
- **Benefit:** Can generate infinite variations without memory spikes.
- **Rendering:** Uses `THREE.InstancedMesh` to draw 1000+ asteroids in 1 draw call.

### 4. Reactive Atmospheres (Proxies)
Atmosphere materials use JS Proxies to map properties directly to shader uniforms.
- **File:** `atmosphere-system.js`
- **Usage:** `atmosphere.intensity = 0.5` automatically updates `gl.uniform1f`.

## 🛠️ How to Extend

### Adding a New Planet
1. Open `theme/assets/js/systems/galaxy-manager.js` (or `legacy/planets.js`).
2. Add an entry to the planets array.
3. The system automatically generates the mesh, atmosphere, and HUD marker.

### Adjusting Physics
1. Open `theme/assets/js/config/constants.js`.
2. Tweak `PHYSICS` constants:
   - `TURN_SPEED`: Rotation sensitivity.
   - `FRICTION`: Inertia decay (lower = more drift).
   - `MAX_SPEED`: Top speed cap.

### Customizing Audio
1. Open `theme/assets/js/systems/audio.js`.
2. `createAmbientSound()` generates the background drone.
3. `FREQUENCIES` array controls the engine pitch per warp level.

## 🐛 Troubleshooting
- **Black Screen?** Check console for `THREE.WebGLRenderer` errors. Usually a shader compilation issue.
- **Lag?** Reduce `PARTICLES.STARS.COUNT` in `constants.js`.
- **Audio Crackling?** The Web Audio API might be overloaded. Refresh to reset the AudioContext.
