Synthèse des expériences et artefacts cités dans le CV, classés côté DevOps/Infra.

## Missions & Services
- **E3CONSEIL (2023–2025)** : déploiement complet tenant Microsoft 365 (sécurité, boîtes aux lettres, RBAC), migration Synology → SharePoint Online, contribution au PCA/PRA (scénarios de crise, RTO/RPO).
- **Infra communautaire (2018–2025)** : clusters hybrides Kubernetes/Istio/vSphere/Proxmox pour serveurs Minecraft et apps conteneurisées, HA/scalabilité, Docker pour modularité.
- **MicroVM & exploration (2020–présent)** : expérimentation Firecracker/Kata/Ignite pour isolation légère et perfs.
- **Observabilité** : mise en place SLI/SLO/SLA, Prometheus/Grafana, alerting, capacity planning.

## Artefacts / Outils
- **KubeFire (2024)** : CLI Go/Shell pour créer/admin des clusters Kubernetes sur microVM Firecracker, compatible kubeadm/K3s/RKE2/K0s, support x86_64/ARM64.
- **ProxomerAsync (2023)** : bibliothèque Python `aiohttp` pour API Proxmox VE, automatisation d’admin de clusters.
- **GameServerBot (2022)** : bot Discord RCON/mcrcon pour orchestrer serveurs Ark/Minecraft (surveillance + notifications).
- **LoginRegisterPage (2021)** : micro-service WebAuthn (Go/JavaScript), déploiement CI GitLab, conteneurisé.

## Stack & plateformes employées
- **Virtualisation/Infra** : vSphere, Proxmox, microVM (Firecracker, Kata, Ignite).
- **Conteneurs** : Docker, Kubernetes (kubeadm, K3s, RKE2, K0s), Istio.
- **CI/CD** : GitHub Actions, GitLab CI.
- **Cloud & M365** : AWS/Azure (pratiques DevSecOps), Microsoft 365/SharePoint Online.
- **Automatisation** : Ansible.

## Compétences transverses
- **RBAC & sécurité documentaire** : modélisation fine des droits et migrations de contenu.
- **Plan de continuité** : définition et formalisation PCA/PRA, RTO/RPO.
- **Onboarding/MDM** : Intune, Windows Autopilot, durcissement Windows Pro.
