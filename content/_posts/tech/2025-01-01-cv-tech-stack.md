Résumé des compétences techniques issues du CV, avec une définition rapide de chaque terme mentionné.

## Langages & Scripting
- **Python (async/multithreading/binding)** : langage polyvalent, supporte l’asynchrone (event loop) et le multithreading ; binding = interfaçage avec du natif (C/C++).
- **Go** : langage compilé concurrent, idéal pour les CLI/réseau (goroutines, channels).
- **JavaScript/TypeScript** : JS côté client/serveur ; TS ajoute typage statique pour fiabilité.
- **Shell/Bash, Batch** : scripting système Linux/Windows pour automatiser tâches et déploiements.
- **C, Pascal, COBOL** : langages compilés (systèmes/legacy) utilisés pour bas niveau ou maintenance.
- **SQL** : langage de requêtes relationnelles pour bases de données.
- **PHP (migration 5 → 8)** : langage web ; migration = mise à niveau syntaxe et extensions.
- **C# (TDD, Clean Architecture)** : langage .NET ; TDD = tests avant code, Clean Architecture = séparation couches.

## DevSecOps & Sécurité
- **WebAuthn** : standard d’authentification forte sans mot de passe via clés publiques.
- **RBAC (Role-Based Access Control)** : permissions accordées selon les rôles, granulaires par ressource.
- **Durcissement Windows Pro / Intune / Autopilot** : politiques de sécurité (chiffrement, MDM, onboarding automatisé).
- **CI/CD sécurisée (AWS/Azure/GitHub Actions/GitLab CI)** : pipelines avec scans, secrets gérés, déploiements contrôlés.
- **ISO 27001 / SOC2 / PCI** : cadres de conformité sécurité/financier ; mise en œuvre des contrôles et preuves.

## Infra & Conteneurs
- **Kubernetes (kubeadm, K3s, RKE2, K0s)** : orchestrateur de conteneurs ; ces distributions/bootstrappers installent et configurent un cluster.
- **Docker** : conteneurisation applicative.
- **HexaCord/BungeeCord (Minecraft)** : proxys/serveurs Minecraft pour sharder et router les joueurs.
- **LXC** : conteneurs système légers.
- **Istio** : service mesh (trafic, sécurité, observabilité pour microservices).
- **vSphere / Proxmox** : plateformes de virtualisation et gestion d’hyperviseurs.
- **microVM (Firecracker, Kata, Ignite)** : VM ultra-légères pour isolation renforcée.
- **Microsoft 365 / SharePoint Online** : suite collaborative ; migration et gestion des droits documentaires.
- **Ansible** : automatisation infra (config, déploiement).

## Observabilité & Fiabilité
- **SLI/SLO/SLA** : indicateurs d’expérience (SLI), objectifs (SLO), engagements contractuels (SLA).
- **Prometheus / Grafana** : collecte métriques et tableaux de bord ; alerting pour disponibilité/capacité.
